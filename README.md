Random Quote Page

A small web page that shows an inspiring quote at the press of a button.
CMPS 510 Final Individual Project





## Features
- 24 quotes with authors
- "New quote" button (never the same quote twice in a row)
- "Copy" button copies quote and author with one click
- Save and remove favourites, kept in the browser with localStorage

## Run it
Open `index.html` in a browser. To run the checks: `npm run build` and `npm test`.

## Tools used
- Plain HTML, CSS and JavaScript
- Node.js built-in test runner and GitHub Actions for automatic checks
